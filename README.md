# OW2 Support Stats

A web app for browsing and **comparing Overwatch 2 support heroes** side-by-side
across the stats that matter for support play: **DPS, healing per second (HPS),
ultimate charge cost, ability cooldowns, survivability**, and a full
ability-by-ability breakdown.

> Stats are curated from the Overwatch wiki and are **approximate as of the
> early-2026 patch**. Support balance changes frequently; values flagged
> `approx` in the UI are best-known estimates. Not affiliated with Blizzard
> Entertainment.

## Features

- **Hero list** — searchable, filterable grid of all 12 support heroes
  (filter by difficulty and healing type).
- **Hero detail** — survivability, weapon/DPS, peak HPS, cooldowns, full
  ability table, and ultimate breakdown.
- **Compare (2–4 heroes)**
  - **Radar chart** — every metric normalized 0–100 across the full roster so
    a higher value always means "stronger" (ult cost and cooldown are
    inverted). Scores are stable regardless of who else is selected.
  - **Stat ranking bar chart** — pick any single metric and see the real, raw
    values sorted best to worst.
  - **Side-by-side ability tables**.
  - Selection lives in the URL (`/compare?ids=ana,mercy`) so comparisons are
    shareable and survive a reload.

## Tech stack

React 18 · TypeScript · Vite 5 · Tailwind CSS · React Router 6 · Recharts 2 ·
Vitest + React Testing Library. Fully static — no backend; the hero dataset
lives in `src/data/heroes/`.

```
  pages/        HeroList, HeroDetail, Compare, NotFound
```

## Data model

Each hero is a `SupportHero` (see `src/types/hero.ts`). A hero's kit is a flat
`abilities[]` array where every numeric field is optional, so burst, beam,
aura, and heal-over-time supports all share one shape. Headline numbers are
surfaced via `weapon`, `healing`, and `ultimate` summary blocks.

Data integrity is enforced by tests (`src/data/heroes/heroes.test.ts`): exactly
12 heroes, unique ids, every hero passes the runtime schema guard, survivability
totals add up, and each stored `weapon.dps` equals `damage × fireRate`.

## Portraits

`public/portraits/*.svg` are themed, locally-committed placeholder portraits
generated by `npm run portraits`. The `HeroPortrait` component additionally
falls back to an initials tile if an image is ever missing at runtime, so the
UI never shows a broken image. Drop real `<id>.svg`/`.png` files into
`public/portraits/` to replace them.
